# Top 3 Cold Demo Candidates

注意：本文件只定义下一阶段候选和 Demo 命题；本轮没有制作、上线或发送 Demo。

## 1. 8Things Eatery — Katoomba

- 官网：https://8things.com.au/index.html
- Maps 复核入口：https://www.google.com/maps/search/?api=1&query=8Things+Eatery+Katoomba
- 公开信号：Wanderlog 聚合 Google 4.5 / 1248；近期仍有评论。
- 可复现痛点：当前官网使用老旧单页结构，且存在 placeholder/lorem-style 文案，直接削弱信任。
- 为什么 AU$800 成立：餐厅本身已有强口碑与图片素材；需要的是把菜单、故事、评价、位置、营业时间和 CTA 做成可信的移动端落地页，不需要开发复杂系统。
- Demo 命题：**“把 Google 上已经被喜欢的餐厅，变成游客点击后也愿意马上到店的页面。”**
- 联系前必核：营业状态、当前菜单、官网控制权、公开邮箱、是否已在改版。
- 不做：在线点餐系统、预订系统、复制完整菜单或图片资产。
- 主要证据：https://wanderlog.com/place/details/981011/8things-eatery

## 2. Mr Pickwick's Fine Old Books — Katoomba

- 官网：https://www.mrpickwick.com.au/
- Maps 复核入口：https://www.google.com/maps/search/?api=1&query=Mr+Pickwicks+Fine+Old+Books+Katoomba
- 公开信号：Wanderlog 聚合 Google 4.4 / 284；官网当前明确表示新网站正在更新。
- 可复现痛点：数字门面处于未完成状态，无法充分呈现三层空间、约 60,000 本书及 vintage/collectible 体验。
- 为什么 AU$800 成立：游客到店决策可由高氛围图片、品类、位置、营业时间和 click-to-call 解决；无需库存型电商。
- Demo 命题：**“不是卖一本书，而是让游客觉得这家书店本身值得专程进入。”**
- 联系前必核：新站是否即将完成；若已有供应商，立即退出。
- 不做：库存同步、电商、未经许可使用书封/店内专业图片。
- 主要证据：https://wanderlog.com/place/details/1005477

## 3. Apsara Day Spa Katoomba — Katoomba

- 官网：https://www.apsarakatoomba.com.au/
- Maps 复核入口：https://www.google.com/maps/search/?api=1&query=Apsara+Day+Spa+Katoomba
- 公开信号：Birdeye 页面显示 4.8 / 177 Google reviews；官网展示 premium treatments 与近年客户反馈。
- 可复现痛点：页面视觉和信息组织明显落后于 premium 服务价格；大量文字没有形成清晰选择路径。
- 为什么 AU$800 成立：单页可以呈现 signature treatments、体验氛围、评价、信任信息和预约 CTA；客户价值高于普通 cafe。
- Demo 命题：**“在顾客预约前，先让网站传达一次完整、安静、可信的 spa 体验。”**
- 联系前必核：当前品牌名、经营者、官网所有权、预约平台链接与服务价格。
- 不做：自建预约/支付系统、医疗或疗效表述、未经许可复制客户照片。
- 主要证据：https://reviews.birdeye.com/apsara-day-spa-katoomba-168916649495019

## 为什么 Top 3 全在同一目的地

这是评分结果，不是地域配额。Katoomba 的三个候选同时满足强经营信号、具体网站缺陷、较高视觉价值与单页可解决性。为降低地域相关性，实际下一阶段不应一次把三份 Demo 都做完：先做 1 个，通过发送/回复数据决定是否继续；若本地样本无反馈，则启用 Daylesford 的 Rubens 或 Larder 作为跨地区备选。
