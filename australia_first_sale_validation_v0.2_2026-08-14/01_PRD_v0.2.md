# 澳大利亚海外小商户网站首单验证 PRD v0.2

更新日期：2026-08-14  
阶段：P0/P1 公开机会研究  
执行角色：有边界的研究执行线程

## 1. 核心目标

完成第一笔真实澳大利亚海外订单。本轮不成交、不联系，仅通过人工公开研究找出第一轮最值得制作 Cold Demo 的 3 个真实商户候选。

## 2. 产品与价格

- 对外产品：Professional Small Business Website
- 内部交付范围：Custom one-page long-scroll website
- 正式价格：AU$800 one-time；不因第一单主动降价
- 付款：AU$400 deposit to start；AU$400 before production launch

## 3. 商业闭环成功标准

1. 真实澳大利亚商户成交；
2. 实际收到约定款项；
3. 网站正式上线；
4. 客户完成验收。

本轮只验证潜在客户质量，不声称上述商业闭环已经通过。

## 4. 第一轮地域策略

- 国家：Australia
- 排除以 Sydney、Melbourne、Brisbane、Perth、Adelaide 为核心的筛选策略
- 不默认优先 Gold Coast 等高度成熟且竞争激烈的大型旅游市场
- 优先：游客消费明显、独立小商户密集、游客依赖 Google Search / Maps 决策、数字呈现存在落差的 regional tourism destinations / towns

## 5. 基础交付范围

包含：

- Custom design
- Responsive desktop / tablet / mobile
- 商户品牌、服务、图片、评价展示
- Hero、Services、About、Reviews、Contact
- Gallery（需要时）
- 一个 Primary CTA
- Click-to-call、Google Maps、social links
- Basic meta title / description
- Domain connection、HTTPS、deployment
- One consolidated revision round

不包含：

- E-commerce、online payment、custom booking system
- CMS、authentication、database、multilingual
- Logo design、professional photography、extensive copywriting
- Ongoing maintenance
- Domain / email / third-party subscription fees

## 6. 所有权与持续费用口径

- Full payment 后最终网站文件 / code 归客户
- Domain 原则上由客户拥有
- 第三方账号原则上由客户拥有；我方仅做必要 setup / configuration / deployment
- 不宣传 zero ongoing costs
- 对外口径：No mandatory monthly maintenance fee from us.
- 第三方实际费用由客户承担

## 7. 本轮流程与交付漏斗

Destination Screening → Merchant Screening → Ranking → Top Prospects

目标漏斗：

- 研究 10–15 个候选目的地
- 选出 Top 3 destinations
- 在 Top 3 中检查 45–60 家 Raw Prospects
- 筛至约 20 家 Qualified
- 形成 Top 10
- 停止在 Top 3 Demo Candidates

## 8. 商户适配原则

核心寻找：Business Quality 高、Digital Presentation 低，且 AU$800 单页产品足以解决主要问题的独立商户。

行业暂不限制；优先游客会通过 Search / Maps 发现，且网站信息与视觉会影响选择的商户。购买概率优先于行业均衡。

## 9. 明确禁止范围

- 不制作或公开 Demo
- 不联系商户，不发送邮件或消息
- 不购买域名、服务或任何付费产品
- 不操作真实商业账户
- 不开发 scraper、prospecting agent、CRM 或批量营销系统
- 不启动 scheduler、cron、timer、service、automation 或 monitor
- 不读取 API Key、Secret、Token、Cookie、SSH Key 或 `.env`
- 不抓取登录后内容、不绕过反爬、不访问私有接口
- 不复制商户代码、品牌素材、图片或完整文案用于商用

## 10. 证据与验收

- 旅游判断优先使用官方 Tourism、州/地方政府、官方 Visitor Economy 资料
- 商户事实只使用公开商业页面、官网、Google Maps/Search 和公开社交页面
- 每个关键判断保留 URL
- 评分、Review 数、联系方式、网站问题和旅游数据不得编造
- 无法可靠访问的信息标记 `evidence gap`
- “网站很丑”不构成购买信号；必须同时审查经营健康、品牌投入、购买能力和联系可能性

## 11. 研究风险与修正

- 风险：搜索摘要或第三方目录过期。修正：优先官网/官方来源，冲突时降级为 evidence gap。
- 风险：把评论多等同购买意愿。修正：Purchase Signal 独立评分并要求品牌投入证据。
- 风险：把连锁或总部控制网站列为候选。修正：人工核所有权与网站控制可能性。
- 风险：单页产品无法解决 booking / commerce 核心问题。修正：此类商户排除或降级。
- 风险：研究者审美偏见。修正：Website Pain 必须记录具体可复现问题，不接受单句 outdated。
