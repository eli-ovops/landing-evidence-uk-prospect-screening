# 澳大利亚海外小商户首单验证｜项目规则

## 项目身份

- 目标：验证澳大利亚海外小商户的首个 **AU$800** 纯静态单页网站订单。
- 进入本项目的会话，在进行 prospecting、客户分析、Demo 准备、邮件/IG 文案、外联规划或交付前，必须先完整读取同目录 [PROJECT_CORE.md](PROJECT_CORE.md)。
- PMO 只治理、派单与验收；具体研究、制作与验证由独立 Owner 完成。

## 产品硬门槛

- 仅静态 HTML/CSS/少量前端 JS；无 CMS、后台、数据库、登录、自建预约、电商、支付、库存或服务端表单。
- 第三方预约仅可外链；我方不登录、不维护第三方系统，也不承担持续内容更新。
- 所有 Demo 制作或准备会话必须先完整读取并遵守 [PROJECT_CORE.md](PROJECT_CORE.md) 中的权威 `Demo Production v1.0`；用户授权制作不等于客户素材授权，也不自动授权发送、公开发布或生产上线。
- `Client-showable Demo` 是 Cold Outreach 中可直接让客户打开、截图和展示的完成品级钩子，不是内部原型、wireframe、草稿或半成品。`内容 35–50%` 只表示选择核心业务切片，不表示页面完成 35–50%；实际展示的 Hero、价值点、2–3 项服务、信任信息、CTA 及移动端必须达到 100% 完成度。
- Demo 禁止占位符、TODO、空白或残缺区块、临时/默认文案、临时图片、死链、假表单、未完成导航、内部说明或“以后再补”的可见痕迹。`Shown in Demo / Reserved for Final Delivery` 只区分范围；Reserved 可不展示，但不得以故意降质、留 Bug 或残缺制造正式交付增量。
- Desktop 与约 390px 必须同时达到可直接发送的视觉、内容和交互完成度；任一不满足固定标记 `CLIENT-SHOWABLE DEMO = FAIL`，不得进入截图、邮件或外联准备。整体方向、信息架构、素材质量或视觉完成度不达标时必须整体重做，不得用零散 P2 修补掩盖根本失败；此门禁不改变客户素材授权、Demo 制作授权、部署或发送授权边界。
- Demo 会话还必须遵守 [PROJECT_CORE.md](PROJECT_CORE.md) `Demo Production v1.0` 的 `Bottom 40% Commercial Architecture` 与独立 QA Gate；这是一组按行业事实选择的收尾策略，不是新的固定页面模板。未发送 Demo 未通过时不得进入外联准备。
- Demo 与每封待发送邮件都必须通过权威 `CLIENT-VISIBLE INTERNAL-TEXT GATE`：Demo 细则见 [PROJECT_CORE.md](PROJECT_CORE.md) 14.4A，邮件发送前细则见 [OUTREACH_EMAIL_SOP.md](OUTREACH_EMAIL_SOP.md)。新内容与未发送草稿立即适用；已发送内容不追溯，重用、重新截图或再次外联时重验。该 Gate 不构成发送授权。

## Prospect 硬门槛

- 所有 prospecting / 筛选会话第一步必须先按 [PROJECT_CORE.md](PROJECT_CORE.md) 执行 `H0 / Gate 0 — Recent Active Trading Evidence`：核验日前滚动 90 天内无合格主动经营证据即固定 `DROP — NO RECENT ACTIVE TRADING EVIDENCE`；受登录墙、验证码、429 或访问阻断而无法核验则固定 `VERIFICATION BLOCKED — RECENT ACTIVITY NOT VERIFIED`。两者均不得继续邮箱/MX、网站问题、评分、Demo 适配或候选推进。
- H0 PASS 后必须先按 [PROJECT_CORE.md](PROJECT_CORE.md) 完成网站状态与互斥通道分类：`TRACK N — NO OWNED WEBSITE` 或 `TRACK W — WEAK EXISTING WEBSITE`；仅搜索不到、归属不明或访问阻断固定 `WEBSITE STATUS UNKNOWN — HOLD`，不得推断为无网站。随后执行对应 `H0.5 / Gate 1 — Strong Transformation Gap`；未通过固定 `DROP — INSUFFICIENT TRANSFORMATION GAP`，Track W 视觉无法实测固定 `VISUAL REVIEW BLOCKED — TRANSFORMATION GAP NOT VERIFIED`，Track N 状态/数字触点无法核验固定 `WEBSITE STATUS UNKNOWN — HOLD`。均不得继续邮箱/MX、H1–H6、100 分评分或 Demo 推进。
- 当前经营、独立或本地可决策；属于“好生意 + 无独立网站或差展示”。阶段性发现投入目标为 Track N 约 60%、Track W 约 40%，不得为凑比例降低任何硬门槛。
- Track W 至少两个可复现的网站问题；Track N 必须完成无独立网站核验，并至少有两个当前官方数字触点的可复现展示缺口；两类都至少需要两个支付能力或品牌投入信号。
- 必须有公开商业邮箱且域名有效，或近 90 天活跃的官方 Instagram。
- 所有筛选会话必须使用 [PROJECT_CORE.md](PROJECT_CORE.md) 中的权威“评分机制 v1.0”，并在候选记录中填写 `Track`、`Website Status` 与 `Website Status Evidence`；评分只排序已通过 H0、Track Classification、对应 H0.5 且已核验证据的商户，不得覆盖 H0、H0.5 或 H1–H6 硬门槛，也不构成 Demo、外联或发送授权。

## 外联与隐私边界

- 所有 Cold Outreach 首封邮件起草会话必须先完整读取并遵守同目录 [OUTREACH_EMAIL_SOP.md](OUTREACH_EMAIL_SOP.md)；不得自由发明首封结构。该 SOP 只规范草稿，不构成发送或合规授权。
- 邮件/IG 私信模板或草稿不等于发送授权。真实外联、登录、提交、部署、付费，均须当前用户对具体目标明确授权。
- 公开邮箱不等于营销同意：逐家记录来源、日期、业务相关性、拒收声明或同意依据；不推测私人邮箱、不批量群发。
- 邮件中的 Demo 链接必须真实、可访问、可点击，并按实际访问状态准确描述；公网但不主动列出的页面只能称 `unlisted concept preview` 或 `independent concept`，不得称 private。HTML 邮件截图只能作预览，不得加入追踪像素、UTM 或任何收件人行为追踪。
- 身份和联系方式仅可在已授权的商户外联或用户要求的签名中使用；不得用于其他项目、公开 Demo、代码、日志或公开发布。

## 客户会话最终回报

- 客户研究、Demo 准备或外联准备会话在最终回 PMO 前，必须先完整读取 [PROJECT_CORE.md](PROJECT_CORE.md)，并按其中 `OUTREACH DRAFT PACKAGE` 契约直接整理收件邮箱证据、个性化主题、纯文本与 HTML 正文、Demo 链接/截图、合规状态、授权状态和阻断项。
- 无可靠邮箱写 `NOT VERIFIED`；无实际 Demo 或截图写 `NOT READY`，不得猜测或假称已完成。
- 整理邮件包仅是草稿交付，不等于发送授权；默认状态固定为 `DRAFT ONLY — NOT AUTHORIZED TO SEND`。

详细价格、签名、模板、合规提醒、筛选与排除项见 [PROJECT_CORE.md](PROJECT_CORE.md)。
