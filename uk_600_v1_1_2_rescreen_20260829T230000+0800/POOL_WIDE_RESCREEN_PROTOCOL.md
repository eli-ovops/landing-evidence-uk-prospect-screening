# UK £600 v1.1.3 whole-pool re-screen protocol

Scope is the immutable historical discovery set `UKR-001` through `UKR-479` in `DISCOVERY_POOL.csv` (479 records). No new discovery is permitted under this task.

Every audit row starts with historical v1.1.2 facts visible but not overwritten. The re-screen must separately verify or HOLD: rolling-90-day H0; attributable identity; Track/website status; public-business-email source; and the v1.1.3 customer-specific persuasion gap. A known old H0 failure is not restated as a present-day closure claim: without current source revalidation it is `HOLD`.

Triage order is auditable rather than a sample: first all rows already carrying both dated `H0 PASS` and public-email `PASS`; then the remaining H0 PASS rows; then all other rows. A row only becomes `SELF-QA PASS` after all gates and the v1.1.3 seven-question record are complete. Every such pass receives a portable evidence package. Any row not currently re-verifiable is retained as `HOLD`, not guessed as rejected.

No row can be marked Independent PASS in this task. The independent reviewer receives only the completed SELF-QA/PASS set and the source packages after the entire pool has a final v1.1.3 PASS, HOLD, or REJECTED disposition.
