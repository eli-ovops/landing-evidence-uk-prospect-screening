## 4. £99 / £199 对老板及对我们的价值

**老板侧：现在尚不能推荐购买。** £99 是现有展示范围的 finished one-page website 成品文件；£199 仅加客户一次集中提交后的一轮合并调整与 QA。两档均不含域名、托管、部署、维护或动态系统。对一位尚未确认上线能力的商户，“买到文件”到“顾客能实际访问”还有执行环节，不能以“价低”消除这个阻力；这也不意味着文件产品是半成品。

£99 若未来有明确使用目标、可交付合法素材与自行/第三方上线路径，才可能是低额的一次性展示投资。£199 的额外价值仅在老板确需一次内容/图片调整时成立，不能把它解释成更多询盘或更好的营销服务。增量流量、预算、利润、支付意愿、购买概率均 UNKNOWN。

**情景假设，不是经营预测**：若其内部把减少重复解释折算为每小时 £30，并且无需额外上线费用，则 £99/£199 分别需要约 3.3/6.6 小时可确认节省才抵回文件价；这些时薪与节省都未被观测，不能作为销售承诺。一般式为“实际节省时间 × 老板自定时间价值 + 可归因新增净贡献 > 文件价 + 上线/域名/托管成本 + 内容沟通时间成本”。当前式中大部分变量 UNKNOWN，无法算回本期。新增一个订单就回本的说法不成立，订单净贡献与是否因网站发生均未核实。

**我们侧：不值得现在优先制作。** 研究已完成，不能因沉没成本或旧分数继续做。一个示例批次若投入 10 小时只实际售出 1 个 £99 文件，毛收入仅 £9.90/小时；若没有成交则为 0，尚未扣工具、沟通、QA和交付成本。这仅是假设算例，不给本客户成交概率。实际制作、独立 QA、获客、售后时间都必须入账，不能只算写 HTML 的时间。此商户现有展示较完整，增量购买理由偏弱，优先找有直接选择/案例/联系问题的候选更合理；无需据此改整个筛选权重。

代部署可能降低文件使用摩擦，但这只是独立服务假设，既非 £99/£199 既有范围，也不是本次授权，更不使用 £599 作为正式报价。

## 6. 最强反对理由、重启条件与最小范围

**反对做网站的最强理由**：现有目录已把服务、实拍、可信评价和联系放在一个可转发页面里，近期还可观察到推荐与重复委托。新单页最确定的变化只是案例排列与品牌自主权；它是否改变老板的工作质量/数量尚无直接证据。没有当前增长触发因素并非单独淘汰理由，关键是已存在低成本替代方案与明显功能重叠。

**反对本报告结论的最强理由**：手机用户要滚过较多平台背书才看到服务与作品，厨柜重涂不能从混合图片得到准确范围。如果老板正在主动争取更多此类项目，自有案例说明与分享入口可能值得 £99。当前缺的不是设计能力，而是“这个用途现在重要、目录解决不了、链接会被使用”的事实。

能推翻“暂不值得”的条件：出现可复核的厨房服务推广/客群调整诉求或实际反复解释/错类询价；确认目录不能承载必要的项目说明；有对应真实清晰素材及可用权；老板已有或明确安排可独立承担的上线路径。无需以隐私敏感数据证明，但本任务未联系老板索取任何资料。只有新证据或用户另行明确指令时重开，不无人值守监控。

若未来成立，最小成品范围仅建议：一张静态响应式单页，Ruislip 服务身份与清晰项目首图；室内/墙纸及手绘厨房的简短范围与各自对应案例；准备/保护与沟通 reassurance；外链 Which 评价；服务区域和 tel/mailto。实际事实切片由经确认的工作类型决定，不强制“双分流”结构。排除整厨安装承诺、假 before/after、报价计算器、表单后台、预约、支付、CMS、动态评价镜像、SEO排名承诺、持续更新、域名/托管/部署及额外来回。
