# JR Renovations：网站价值研究

2026-09-08｜结论：**有条件值得**｜可信度：**MEDIUM**。

当前最合理顺序是先改善现站的项目适配说明和手机联系路径，再考虑用独立静态单页替换首页式展示。JR 有可信业务与展示缺口，但没有证据证明老板现在缺客户、愿意买网站或需要重做整站。既有独立筛选 80/A 仅保留为资格历史，本报告不修改该包，也不把分数转成购买概率。

## 1. 当前获客与已有能力

[Which 资料及评价](https://trustedtraders.which.co.uk/businesses/jr-renovations/)给出三类可归属的历史获客线索：2024 年客户因看过邻居工程而选择；2022 年评价描述自 2006 年以来反复聘用；2016 年客户明确依据该平台评价选择。它们证明转介绍、复购、平台信任曾发挥作用，不证明今天各渠道占比。2026 年 8 月厨房项目与商户回复支持当前经营；不能据此推断营销预算或增长需求。

现有体系已经解决相当多问题：Which 集中显示评分、客户经历、服务说明和联系入口；官网提供品牌身份、服务清单、作品、评价导航、电话、邮箱与投诉说明。官网主动让访客先看作品和评价，路径有商业意图。社媒的可归属账号、广告投放、搜索流量、转介绍占比及当前接单容量均为 UNKNOWN。

## 3. 三种方案比较

| 方案 | 何时最合理 | 对 JR 的当前判断 |
|---|---|---|
| 不做新网站，继续现有渠道 | 容量已满、转介绍/Which 足够，或网站并非主要接触点 | 完全合理的备选；容量未知，所以不能认定其必须购买。零新页成本但保留现站窄屏摩擦。 |
| 修现站/目录 | 现维护者可低成本调整：整修定位提前、作品加空间标签、响应式重排、直接联系；保留 Which 作为评价权威 | **当前首选的最小干预。** Which 已含关键定位，不必重复修同一事实；应优先让官网与之同步。维护权限、源码可改性、实际报价未知，因此“便宜”仅为条件，不伪称已拿报价。 |
| 独立静态单页 | 旧固定布局改造成本接近重建，老板要一个便于转发的厨房/浴室整修入口，且能接手部署 | **有条件值得。** 在自有域名中整合项目适配→真实空间证明→外部评价→询盘，商业用途明确。无需新增域名，也不应平行制造无人访问的新站。 |

“新单页优于修站”的必要差别是重新组织整条房主判断路径，而非只改字号。但经过本次反证，尚不能排除现站维护者用较小改动取得大部分收益；因此不建议标成“值得优先做”。

## 4. £99/£199 对双方是否值得

唯一现行 Offer：GBP / £99 AS-SHOWN HANDOVER，或 £199 ONE PERSONALISED UPDATE。£99 是当前可见范围的完成品静态文件；£199 增加客户集中提供内容后的一轮合并修改与 QA。二者均不含域名、托管、部署、维护或持续支持。£599 仅此前讨论，未作为本报告报价；不分析未经授权的代部署套餐。

**对老板：**若已有维护者能接收文件，且希望向转介绍房主发一张清晰的项目匹配页，£99 有可解释的用途；若需要把近期项目和实际服务边界集中补进来，£199 更适合一轮事实/图片更新。若老板无法接手上线，单纯购买文件的实际使用路径尚未闭合，即使文件是完成品，也不能假定购买后自动改善获客。客户权利确认、承接部署方、是否需要更合适项目应先有答案。

仅供决策的时间价值情景，**不是 JR 的实际收益或预测**：若某老板把可支配时间估为 £30/小时，只靠解释时间节省覆盖购买价，£99 需累计约 3.3 小时，£199 需约 6.6 小时；实际能否节省 UNKNOWN。若没有新增合格询盘、没有时间节省，则获客收益为零。不能用“装修一单金额大”推出网站必回本；收入、利润、订单增量与转化率均未测得。

**对我们：**值得保留为有明确商业切片的受控验证对象，暂不值得无条件投入高成本多轮制作。假设未来包含准备/制作/QA/获客/交接共投入 2 小时且成功售出，毛收入时间比为 £49.5/小时或 £99.5/小时；若共 4 小时则为 £24.75/小时或 £49.75/小时，均未扣成本、税费和失败候选时间。没有成交则为零。没有可靠购买概率，不能算期望利润或据此选为五家第一。

30–60 分钟是 Core 制作目标而非本次已证实工时；素材授权与旧站接替可能增加成本。本次 Actual Demo Minutes = 0。

- 官网 Logo、施工/完工图片是官方发布线索；本次只保存研究截图，没有下载媒体作为 Demo。浴室 lightbox 证明现有真实比较可用作研究参考，但年代、原图质量、作者、房主隐私及最终转让权均待核实。
- Which My work 是业务关联的第三方托管线索；不能仅凭托管位置认定客户版权或已授权。B 级归属需要逐图证明，最终 source-transfer eligibility = UNKNOWN。
- 新近评价不能与旧 gallery 图片自动配对，不能把旧图写成 2026 年厨房项目；施工范围不详的图片不补造工期、地址、价格或前后关系。
- 用精致概念室内图替代真实案例会削弱本案核心证明。概念图可以表达空间氛围，但不得暗示 Roman 完成该工程；若真实项目不足，应降低推进优先级，而非制造作品。

## 6. 最大反证、条件与最小范围

**最强反对理由：**现有平台、口碑和作品已经足以让部分房主选中 JR；没有证据证明网站是业务瓶颈，且项目周期可能占用交付容量。旧评价提及曾经难约只能作为历史反证，不能声称现在满单。新页可能仅重排已经有效的信息，修站更经济。

将建议提升为“值得优先做”的条件：确认老板确实要更合适的厨房/浴室整修项目或频繁转发项目介绍；拥有可核验、可继续使用的相关作品；明确已有上线接手者；旧站达到同样信息路径的维护成本不优于新单页。这些条件未确认前保持有条件。

将建议推翻为“暂不值得”的条件：老板现有渠道已满足容量且不需要筛选说明；只想免费修 SSL；维护者可快速交付等效改进；需要的是 CMS、持续获客运营、报价系统或包上线服务；关键真实素材无法使用且概念替代无法诚实提供项目证明。不要因未公开增长意愿单独淘汰。

最小可行范围建议（仅研究建议，不是 Pre-code 或制作授权）：

1. Charlton/London 区域与厨房、浴室整体整修定位，保留独立小工未必承接的准确语义，不能写绝不接。
2. 两类房间与一类相连空间整修说明，配可确认归属的不同项目视觉；保留选择具体项目所需的简短语境。
3. 有来源的客户经历摘要与 Which 原始评价外链，说明先沟通范围、现场评估；不承诺固定价或立即可约。
4. 可读电话/邮箱入口，建议顾客说明地区、房间与拟改范围；无收集表单、无自动报价，保留适用投诉/身份信息。

排除：后台、登录、支付、CRM、项目管理、实时排期、维护、SEO 流量保证、代运营、全业务多页重建、域名/部署。核心价值是合适项目的理解与信任，并非重新证明他有生意。
